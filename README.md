# Flight Booking Testing Project

## Project Overview

This project focuses on testing a flight booking web application through manual testing and web automation.

## Testing Activities

- Designed and executed test cases for flight search and booking functionality
- Tested flight selection and booking workflow
- Validated search results and input fields
- Performed positive and negative test scenarios
- Automated selected test scenarios using Selenium with Python and PyTest
- Documented test results and identified defects

## Tools & Technologies

- Python
- Selenium WebDriver
- PyTest
- PyCharm
- Git & GitHub

## Test Scenarios

1. Search for flights using valid details
2. Validate departure and destination inputs
3. Select available flight
4. Continue through the booking process
5. Validate required passenger information
6. Verify invalid or incomplete input handling
7. Validate booking workflow

## Project Outcome

The project provided practical experience in web application testing, test case execution, automation, result validation, and test documentation.
